# SNK Business

Premium multi-business administration starter for GitHub Pages.

## Pages
- `index.html` — public landing page
- `login.html` — separate login page
- `dashboard.html` — main dashboard
- `admin.html` — administration control center
- `browser-ui.html` — Super Admin website UI editor
- `business.html` — business workspace
- `customers.html` — premium customer management

## Important
This is a static GitHub Pages prototype. The credentials and localStorage/sessionStorage authentication are demo-only and are NOT suitable for production security. For real deployment, replace authentication with a server/Firebase/Supabase backend and never store real passwords in frontend files.
